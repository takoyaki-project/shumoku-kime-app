# 種目決めアプリ

甲子園一番町（甲一）子供会の、町内会運動会 参加種目わりあてを自動化するツールです。
これまで役員が手作業でExcelに行っていた「集計・種目決定」を代わりに行います。
名簿との突き合わせ（名寄せ）は行いません（大人の名簿が存在しないため）。Googleフォームの回答CSVだけを情報源とします。

**毎年担当者が交代する前提で作られています。プログラムの知識がなくても、以下の2ステップだけで使えます。**

## 使い方

1. `index.html` をダブルクリックしてブラウザで開く（インターネットに接続されたパソコンで）
2. Googleフォームの回答CSVを欄に貼り付けて「実行する」を押す
3. 結果を確認し、「Excel（.xlsx）をダウンロード」を押すと保存される

「サンプルデータで試す」ボタンを押すと、テスト用のダミーデータで一連の流れを体験できます。

**このアプリは一切サーバーと通信しません。** 読み込んだ回答・出力結果は、このパソコンのブラウザの中だけで処理され、外部には送信されません。

## 困ったときは

このツールが動かない・結果がおかしいと感じたときは、無理に使わず、**手作業（手打ちでExcelに転記するやり方）に戻ってかまいません。** それでも運動会は成立します。

## 出力されるExcelの見方

- 1シートに、種目ごとの出場者一覧がまとまっています。
- 「要確認」列に何か書かれている行は、自動では決められなかったケースです。人の目で最終判断してください（（未割当）として一覧の先頭にまとまっています）。
- 「備考」列には、本人がフォームに書いた自由記述（ペア希望など）がそのまま残っています。ペア希望がある人は、同じ種目に割り当てられているか備考欄を見比べて確認してください。
- 定員に対して希望者が足りなかった種目には、氏名欄に「欠員」と入った行が不足人数分だけ追加されます。実際に埋める作業は人力です。

## 割り当てロジックの考え方（概要）

詳しくは `うんどうかい係_設計ブリーフ.md` を参照してください。概要は以下の2段階ですが、優先順位（チェックした種目数が少ない人ほど高い）は両段階を通じて固定なので、実装上は1つのループで実現しています。

1. **保証パス**：まだ1つも出られない人をゼロにする。希望（チェック）した種目数が少ない人から先に、残り枠が少ない種目を優先して割り当てる。
2. **希望の上乗せパス**：全員に1つ行き渡ったあと、同じ優先順のまま、残りの希望を埋められるだけ埋めていく（申告数の上限はない）。

出場希望は「チェックの有無」のみで、○×のような拒否の概念はありません。定員割れした種目に無記入の人を自動で回す「おまかせ埋め」は行わず、不足分はExcelに「欠員」行として出力します。自動で解決できない矛盾（唯一の希望が満員など）は、Excelの「要確認」列にフラグを立てて人が判断します。

学年の内訳（1年・2年・3年など）は、回答データが学年帯（1〜3年／4〜6年）でしか持っていないため、同じ学年帯の中では合算した1つの枠として扱っています。データの粒度上の割り切りです。

同一人物による重複送信（入力ミスでの再送信等）は、「名前」「年齢」「性別」が完全一致する行のうち、タイムスタンプが最も新しいものだけを残します。タイムスタンプが読み取れない場合は全件を出力し、「要確認」列に重複疑いのフラグを立てます。

## 技術的なこと（開発者向け）

- 素のHTML/CSS/JS。ビルド不要。サーバー不要。
- CSV解析: [PapaParse](lib/papaparse.min.js)、Excel書き出し: [SheetJS](lib/xlsx.full.min.js)（どちらもブラウザ内蔵で完結、外部CDNには依存しない）
- `src/core.js`：重複統合・割り当てロジック本体（DOM非依存、Node.jsからも読み込んでテスト可能）
- `src/events-master.js`：`種目マスタ.json` をブラウザで直接開いても読み込めるようJS化したもの。種目内容を変えたときはJSON側を編集した上で作り直すこと。
- `src/app.js`：画面まわりの処理
- `test/run-tests.js`：`node test/run-tests.js` でサンプルデータに対する動作確認ができる

### 種目マスタを更新する場合

`種目マスタ.json` を編集したあと、`src/events-master.js` の中身（JSONを埋め込んだ部分）を編集後の内容に合わせて作り直してください。
