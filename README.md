# うんどうかい係

甲子園一番町（甲一）子供会の、町内会運動会 参加種目わりあてを自動化するツールです。
これまで役員が手作業でExcelに行っていた「名寄せ・集計・種目決定」を代わりに行います。

**毎年担当者が交代する前提で作られています。プログラムの知識がなくても、以下の3ステップだけで使えます。**

## 使い方

1. `index.html` をダブルクリックしてブラウザで開く（インターネットに接続されたパソコンで）
2. 名簿CSVと、Googleフォームの回答CSVを、それぞれの欄に貼り付けて「読み込んで名寄せする」を押す
3. 「候補あり／不明」と出た人だけ確認し、「この内容で次へ進む」→「実行する」を押す
4. 「Excel（.xlsx）をダウンロード」を押すと結果が保存される

「サンプルデータで試す」ボタンを押すと、テスト用のダミーデータで一連の流れを体験できます。

**このアプリは一切サーバーと通信しません。** 読み込んだ名簿・回答・出力結果は、このパソコンのブラウザの中だけで処理され、外部には送信されません。

## 困ったときは

このツールが動かない・結果がおかしいと感じたときは、無理に使わず、**去年までの手作業（手打ちでExcelに転記するやり方）に戻ってかまいません。** それでも運動会は成立します。

## 出力されるExcelの見方

- 1シートに、種目ごとの出場者一覧がまとまっています。
- 「要確認」列に何か書かれている行は、自動では決められなかったケースです。人の目で最終判断してください（（未割当）として一覧の先頭にまとまっています）。
- 「備考」列には、本人がフォームに書いた自由記述（ペア希望など）がそのまま残っています。ペア希望がある人は、同じ種目に割り当てられているか備考欄を見比べて確認してください。
- 「システムメモ」列には、希望したが対象外だった種目についての補足などが入ることがあります。
- 末尾に「リレー（町内対抗）」の希望者一覧が参考情報として付いています（自動割り当てはしていません）。

## 割り当てロジックの考え方（概要）

詳しくは `うんどうかい係_設計ブリーフ.md` を参照してください。概要は以下の3段階です。

1. **保証パス**：まだ1つも出られない人をゼロにする。希望が少ない（選択肢が狭い）人から先に、残り枠が少ない種目を優先して埋める。
2. **希望の上乗せパス**：全員に1つ行き渡ったあと、本人が「出られそう」と申告した種目数まで、残りの希望を埋めていく。
3. **おまかせ埋め**：それでも埋まらない種目に、無記入（おまかせ）の人を、申告した種目数の上限を超えない範囲で回す。

「×（避けたい）」と答えた種目には絶対に割り当てません。自動で解決できない矛盾（唯一の希望が満員など）は、Excelの「要確認」列にフラグを立てて人が判断します。

学年の内訳（1年・2年・3年など）は、名簿・回答データが学年帯（1〜3年／4〜6年）でしか持っていないため、同じ学年帯の中では合算した1つの枠として扱っています。データの粒度上の割り切りです。

## 技術的なこと（開発者向け）

- 素のHTML/CSS/JS。ビルド不要。サーバー不要。
- CSV解析: [PapaParse](lib/papaparse.min.js)、Excel書き出し: [SheetJS](lib/xlsx.full.min.js)（どちらもブラウザ内蔵で完結、外部CDNには依存しない）
- `src/core.js`：名寄せ・割り当てロジック本体（DOM非依存、Node.jsからも読み込んでテスト可能）
- `src/events-master.js`：`種目マスタ.json` をブラウザで直接開いても読み込めるようJS化したもの。種目内容を変えたときはJSON側を編集した上で作り直すこと。
- `src/app.js`：画面まわりの処理
- `test/run-tests.js`：`node test/run-tests.js` でサンプルデータに対する動作確認ができる

### 種目マスタを更新する場合

`種目マスタ.json` を編集したあと、`src/events-master.js` の中身（JSONを埋め込んだ部分）を編集後の内容に合わせて作り直してください。

## 今回（MVP）でやらなかったこと
